# jvc-lp20465-012
Archival documentation and infrared-code capture for the JVC LP20465-012 MBR remote supplied with JVC dual-deck DV/S-VHS editing equipment. Includes complete command maps, raw timing data, A/B remote modes, jog/shuttle behavior, PCB photographs, and reusable exports.
