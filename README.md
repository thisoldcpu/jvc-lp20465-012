# JVC LP20465-012

Archival documentation and infrared-code capture for the JVC LP20465-012 MBR remote supplied with JVC dual-deck DV/S-VHS editing equipment.

This repository includes command maps, raw timing data, A/B remote modes, jog/shuttle behavior, PCB photographs, and reusable infrared exports.

Disassembly is straightforward.

The enclosure is secured by six matching black screws:

- four corner screws on the rear housing
- two screws beneath the battery cover

Once the enclosure is open, the PCB is retained only by the jog/shuttle assembly. Remove the four larger silver screws securing that assembly.

There should be ten screws in total:

- six black enclosure screws
- four silver jog/shuttle assembly screws

Lift the PCB and jog/shuttle assembly carefully, as the outer shuttle ring and center jog knob are separate components once released.
